# Portafolio personal

Portafolio web de Andrés Jaramillo, desarrollado con HTML, Tailwind CSS y CSS personalizado.

## Secciones

- Inicio
- Sobre mí
- Habilidades
- Experiencia y proyectos
- Educación
- Contacto

## Proyectos destacados

- **Rueda Libre:** sitio web de alquiler de bicicletas y recorridos por Medellín. [Visitar sitio](https://andresriwi.github.io/rueda-libre/).
  - Tecnologías: HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons y Google Fonts.
- **GreenBox:** plataforma con información sobre reciclaje, compostaje y cultivo de plantas. [Visitar sitio](https://juanpmorales.github.io/GreenBox/).
  - Tecnologías: HTML5, CSS3 y Bootstrap 5.3.

## Tecnologías del portafolio

- **HTML** (`index.html`): estructura y contenido de las secciones.
- **Tailwind CSS:** se carga desde CDN; su configuración de colores y fuentes está en `index.html`.
- **CSS personalizado** (`styles.css`): fondo, texto con contorno y ajustes para movimiento reducido.

## Cómo verlo

Abre `index.html` en un navegador. Se necesita conexión a internet para cargar Tailwind CSS desde su CDN.

## Personalización

Edita `index.html` para cambiar el contenido, los enlaces y los datos de contacto. Los estilos personalizados están en `styles.css`.
