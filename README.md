# Portafolio personal

Portafolio web de Andrés Jaramillo, desarrollado con HTML, CSS y Tailwind CSS.

## Tecnologías y estilos

- **HTML** (`index.html`): contiene la estructura y el contenido de cada sección.
- **Tailwind CSS**: se carga desde CDN. Sus clases utilitarias se usan directamente en los atributos `class`, por ejemplo `text-acid`, `px-6` y `md:flex`.
- **Configuración de Tailwind** (`index.html`): amplía la paleta con colores como `ink`, `paper` y `acid`, además de definir las fuentes.
- **CSS personalizado** (`styles.css`): contiene los estilos que no son utilidades de Tailwind, como el fondo cuadriculado, el texto con contorno y los ajustes para movimiento reducido.

## Personalización

El portafolio incluye las secciones Inicio, Sobre mí, Habilidades, Educación y Contacto. El correo y el enlace de GitHub se encuentran en Contacto.
